## Integration Checklist

After each image is generated:

- [ ] Convert to WebP format (quality 85)
- [ ] Verify file size < 200KB for illustrations, < 500KB for photos
- [ ] Add to Next.js `Image` component with proper `width`, `height`, `alt`
- [ ] Set `loading="lazy"` for below-fold images
- [ ] Verify responsive rendering at 320, 768, 1024, 1440px
- [ ] Check dark mode compatibility (or add dark variant)
- [ ] Ensure meaningful `alt` text for informative images, empty `alt=""` for decorative
- [ ] Run Lighthouse to verify no LCP regression
- [ ] Commit with descriptive message

## Generation Command Template

```bash
curl -s "https://api.x5m5x.com/v1/images/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${IMAGE_API_KEY}" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "<PROMPT_FROM_ABOVE>",
    "n": 1,
    "size": "<SIZE_FROM_ABOVE>",
    "quality": "high"
  }'
```

Response contains base64-encoded image data. Decode and save:

```bash
echo '<base64_data>' | base64 -d > <output_filename>
```
